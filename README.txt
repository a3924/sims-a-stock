============================================================
  我的模拟人生·A股版  ——  离线单机炒股模拟游戏
============================================================

【游戏简介】
用 20 万本金，在 2021–2026 真实 A 股日 K 数据中操盘 242 个交易日
（约一年）。从每局随机抽出的 15 只股票池里低买高卖，比拼收益率、
夏普比率与择时/选股能力。数据全部内置，无需联网。

------------------------------------------------------------
一、怎么打开（两种方式，任选其一）
------------------------------------------------------------

方式 A · 最简单（双击即玩）
  直接双击本文件夹里的  index.html  ，浏览器打开即可游玩。
  ⚠ 注意：以这种方式（file://）打开时，部分浏览器（尤其 Chrome）
    出于安全限制，可能不会持久化「存档」（关闭网页后下次打开找不到
    进度）。适合一次性游玩，或只用当前会话。

方式 B · 推荐（存档最稳，需本机有 Python 3）
  ▸ Windows：双击  start.bat
  ▸ Mac / Linux：在终端里运行  ./start.sh
  脚本会自动启动本地服务器并打开  http://127.0.0.1:8123 ，
  存档会 100% 稳定（浏览器在 http 域下正常保存 cookie/localStorage）。
  关闭启动脚本所在的黑窗口即停止游戏。

------------------------------------------------------------
二、存档说明（临时存档 · 写入浏览器）
------------------------------------------------------------
• 游戏会自动把当前进度存进你的浏览器（cookie 为主，localStorage 兜底）。
• 关闭网页后再打开：选股界面若检测到存档，会出现
  「继续上次存档 ↺」按钮，点它即可接着上次的进度玩。
• 游戏进行中随时点顶栏的「清除存档」可主动抹掉进度。
• 开新局（点「开始交易」或结算后「再来一局」）会自动放弃旧存档。
• 存档仅在同版本游戏内有效；若将来换了新版本，旧存档会被安全忽略。

提示：若你用方式 A 双击打开、又发现刷新后进度丢失，请改用方式 B
（本地服务器）即可稳定存档。

------------------------------------------------------------
三、基本操作
------------------------------------------------------------
• 选股界面：左侧 15 只股票，下方 4 张 K 线面板（滚轮缩放 / 拖动平移 /
  双击复位）。点「开始交易」进入游戏。
• 游戏内：
    - 下一天 ▶ / +5天 / +20天 ：推进交易日（T+1 规则生效）
    - 买入(B) / 卖出(S) / 全仓买 / 全卖 ：按手数交易（100 股=1 手）
    - 多图切换 ：同窗口对比个股与各大指数
    - 结算本局游戏 ：清算全部资产，生成结算报告（收益/夏普/择时/选股等）
    - 清除存档 ：抹掉浏览器中的进度
• 快捷键：→ 下一天，↓ +5 天，B 买，S 卖（游戏内有效）。
• 真实起止日期默认隐藏（只显示相对交易日 T0/T+n），仅在结算页点
  「显示真实日期」揭晓。

------------------------------------------------------------
四、技术说明
------------------------------------------------------------
• 纯静态网页（HTML + Canvas），无任何外部依赖、不联网。
• 本地服务器模式（方式 B）每次加载都会强制拉取最新代码，避免浏览器
  缓存旧版导致显示异常。
• 数据包：index.html / app.js / chart.js 为程序；data_*.js 为内置行情。
  请勿单独删除 data_*.js，否则游戏无法启动。
